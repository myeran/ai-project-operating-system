# החלטה ארכיטקטונית — גילוי Runtime גלובלי

## החלטה

ה־Runtime נשאר שירות מרכזי יחיד. `project-navigator` מקבל גשר גלובלי שמאתר את
שורש המאגר לפי סדר עדיפויות: משתנה `AI_PROJECT_OS_ROOT`, רישום ב־
`~/.codex/project-navigator/runtime.json`, תיקיית העבודה וההורים שלה, ולאחר מכן
מיקומים מקומיים נפוצים.

## בעלות ומצב

- Runtime API, SQLite, Registry ו־Skills נשארים בבעלות המאגר המרכזי.
- `runtime.json` הוא רישום חיבור מקומי בלבד; הוא אינו Project State.
- תיקיית הפרויקט הנוכחית נשלחת כ־`workspace_location`, ולכן תוצרי הפרויקט נשארים
  בתיקייה שבחר המשתמש.

## אינווריאנטים

- אין שכפול Runtime או מסד נתונים לכל תיקייה.
- ההפעלה idempotent וללא פתיחת דפדפן.
- אם אין Runtime שניתן לאתר, הבקשה נכשלת בצורה ברורה ולא ממציאה חיבור.
